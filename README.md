## About The Project

Landing Pages Framework helps developers put together polished landing pages without rebuilding the same sections over and over. It gives teams a set of ready-made components they can drop in, tweak, and reuse across projects. That means less boilerplate and faster page launches.

## Getting Started

To get a local copy up and running, follow these steps.

### Prerequisites

* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Mayorkun27/landing_pages_framework.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Start the development server
   ```sh
   npm run dev
   ```

## Usage

Import any component you need and drop it into a page.

```tsx
import { Navbar } from "./components/Navbar";
import { PageHeader } from "./components/PageHeader";
import { Footer } from "./components/Footer";
import { Modal } from "./components/modal/Modal";
```

Each component is self-contained, so you can arrange and style them however your landing page requires.

_For more examples, please refer to the [Documentation](https://github.com/Mayorkun27/landing_pages_framework)._
